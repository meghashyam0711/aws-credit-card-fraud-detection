AWS COMPUTE

AWS Lambda (Python 3.12)

Serverless Inference Engine

AWS Lambda performs serverless inference by parsing the incoming HTTP API v2.0 event, validating the 29 numeric features, preparing the feature vector in exact feature_names_in_ sequence, standardizing ONLY the Amount column with StandardScaler, loading the ML artifacts when required, running the Scikit-Learn Random Forest model, and returning the prediction and risk score.
